# Fuentes consultadas para verificar correcciones técnicas

Los textos de preguntas originales provienen de los PDF del usuario. Las preguntas PLUS fueron redactadas para práctica a partir del temario de esos PDF; no son preguntas publicadas en SIMA.

- HTML, etiqueta de imagen: https://developer.mozilla.org/es/docs/Web/HTML/Reference/Elements/img
- HTML, elemento input y atributo `type`: https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/input
- Guía de Scrum, objetivo del Daily Scrum: https://scrumguides.org/scrum-guide.html
- Método ARID, SEI (dos fases y nueve pasos): https://resources.sei.cmu.edu/asset_files/technicalnote/2000_004_001_13685.pdf
- Información de ARID, Software Engineering Institute: https://sei.cmu.edu/library/active-reviews-for-intermediate-design-arid/
- Node.js HTTP, `IncomingMessage`: https://nodejs.org/api/http.html
- API de Server de Socket.IO: https://socket.io/docs/v4/server-api/
- API de Express Response: https://expressjs.com/en/4x/api/response/
- Skipfish, documentación del proyecto: https://github.com/skipfish-go/skipfish
- Algoritmo Ricart–Agrawala y relojes de Lamport: https://people.cs.rutgers.edu/~pxk/classes/417/notes/mutex.html

Las respuestas pueden depender de cómo esté formulado un enunciado. Cuando falta una respuesta única, la pregunta queda marcada **En revisión** en lugar de asignarle una clave con falsa certeza.
